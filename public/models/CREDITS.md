### Note on a near-miss (excluded)

poly.pizza also lists an "Animated Zombie" by Quaternius (https://poly.pizza/m/jkrEvQZb8J)
with a nicer animation set, but poly.pizza's own license field reports it as
**"CC-BY 3.0"**, not CC0 — it was excluded to satisfy the CC0-only requirement.
The canonical Quaternius **Zombie Apocalypse Kit** (quaternius.com/packs/zombieapocalypsekit.html,
explicitly CC0, contains 4 playable characters + 4 zombie enemies + vehicles/props all in one
consistent style) could not be downloaded in this session: its only distribution link is a
Google Drive folder (`drive.google.com/drive/folders/1mWP6sCHun7OUMHQeDNZLrXTteXlzWg_t`) that
returned "Quota exceeded" for every file fetched (anonymous Drive rate-limit, resets ~24h).
Retry that folder later for a fully-matched player/zombie/vehicle set from one pack; the files
we did ship are a very close style match (same author, same low-poly Quaternius look).
